# E-Commerce SQL Database Project

## 📌 Project Overview

This project is a complete e-commerce database developed using MySQL.

It demonstrates how SQL can be used to design a relational database, manage business data, and perform business analysis using real-world e-commerce scenarios.

## 🛠️ Technologies Used

- MySQL
- MySQL Workbench
- SQL
- GitHub

## 🗄️ Database Tables

The database contains the following tables:

1. Customers
2. Categories
3. Products
4. Orders
5. Order Items
6. Payments
7. Reviews

## 🔗 Database Relationships

- Customers → Orders
- Categories → Products
- Orders → Order Items
- Products → Order Items
- Orders → Payments
- Customers → Reviews
- Products → Reviews

## 📊 SQL Concepts Demonstrated

- Database and table creation
- Primary Keys
- Foreign Keys
- Constraints
- INSERT / SELECT
- INNER JOIN

- Aggregate Functions
- Subqueries

- Common Table Expressions (CTEs)
- Window Functions

- EXPLAIN
- Stored Procedures
- Transactions
- COMMIT
- ROLLBACK

## 📈 Business Analysis

The project analyzes:

- Total customers
- Total products
- Product stock levels
- Customer orders
- Customer spending
- Product sales
- Category revenue
- Payment status
- Order status
- High-value customers
- Product price categories
- Revenue rankings

## 📂 Project File

`ecommerce_project.sql`

This file contains the database creation, sample data, SQL analysis queries, views, indexes, and other SQL concepts demonstrated in the project.

## 🎯 Project Objective

The main objective of this project is to demonstrate practical SQL and database skills by building and analyzing an e-commerce database from the ground up.
